# 연결 리스트 도서 관리 프로그램

C의 구조체와 단일 연결 리스트로 도서를 관리하는 Windows 콘솔 프로그램이다. 도서 등록부터 대출·반납 상태 변경, 전체 목록 조회까지 메뉴 방식으로 처리한다.

## 주요 기능

- 제목과 출판 연도를 입력해 연결 리스트 끝에 새 도서 추가.
- 제목으로 도서를 찾아 대출·반납 상태 변경.
- 등록 순서, 출판 연도, 대출 상태, 제목을 목록으로 출력.
- 메뉴 선택을 반복 처리하고 종료.

각 노드는 제목, 출판 연도, 대출 상태와 다음 노드 포인터를 보관한다. 데이터는 실행 중 메모리에만 유지된다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `openswbase/도서관리.c` | 자료구조와 콘솔 메뉴 구현 |
| `openswbase.sln` | Visual Studio 솔루션 |
| `openswbase/openswbase.vcxproj` | Windows 콘솔 프로젝트 설정 |

## 빌드 및 실행

프로젝트는 Visual Studio 2019 형식, MSVC `v142`, Windows SDK `10.0`을 사용한다. Debug·Release 및 x86·x64 구성이 포함되어 있다.

1. C/C++ 데스크톱 개발 도구가 설치된 Visual Studio에서 `openswbase.sln`을 연다.
2. 필요하면 설치된 도구에 맞춰 플랫폼 도구 집합과 SDK를 재설정한다.
3. 구성을 선택해 빌드한 뒤 콘솔에서 실행한다.

메뉴는 `0` 신규 등록, `1` 대출, `2` 반납, `3` 목록 출력, `4` 종료다. 이번 문서 정리에서는 빌드·실행을 수행하지 않았다.

## 구현 범위

- 파일·데이터베이스 저장 기능이 없어 종료하면 등록 내용이 사라진다.
- 등록하지 않은 제목을 검색하는 경우와 중복 대출·반납 상태에 대한 예외 처리가 필요하다.
- 입력 길이 제한과 메모리 해제 등의 보완이 남아 있다.

별도 라이선스 파일은 포함되어 있지 않다.
